# Anmol Healing Hub

Create a highly performant, ultra-fast, clean, and modern E-commerce Web Application for an authentic herbal clinic named "Anmol Dawakhana" (انمول دواخانہ).

### Core Features & Technical Requirements:

1. High Performance & Scalability:

   - Optimize for high traffic (handling thousands of active concurrent users).

   - Lightweight, fast-loading UI with efficient code splitting and lazy loading for images/products.

   - Mobile-first, fully responsive design (smooth on low-end mobile devices and high-end desktops).

2. Dual Language Support (Bilingual UI):

   - Toggle button at the top header for switching between Simple English and Simple Urdu (اردو).

   - Full Right-to-Left (RTL) layout support when Urdu is selected, and Left-to-Right (LTR) for English.

   - Use clean, easily readable Nasta'liq/Urdu web fonts for Urdu text and clean Sans-Serif font for English.

3. Design & Branding (Neat, Clean & Simple):

   - Theme: Natural, herbal, and trustworthy feel (Soft Organic Green, Emerald, Warm Cream, and Crisp White accents).

   - Minimalist, clutter-free, and easy-to-navigate layout for users of all age groups.

4. Key Sections & Pages:

   - Header: Dawakhana Logo ("Anmol Dawakhana"), Navigation menu, Search bar, Cart icon with item counter, Language Switcher (EN / اردو).

   - Hero Banner: Elegant banner highlighting "Pure Herbal Remedies & Authentic Ayurvedic/Tibbi Medicines" (خالص جڑی بوٹیوں سے تیار کردہ ادویات).

   - Product Catalog / Categories:

     - Categories like Herbal Teas (جووشاندے/چائے), Essential Oils (روغنیات), Immunity Boosters, Tonic/Syrups (شربت), General Wellness (معجون/سفوف).

     - Filter and Search options for easy product discovery.

   - Product Card: Clean design with product image, clear title (in selected language), price, weight/pack size, rating, and a prominent "Add to Cart / Buy Now" button.

   - Product Detail Page: Full description, health benefits, key ingredients, usage instructions/dosage (طریقہ استعمال), and customer reviews.

   - Simple Checkout System:

     - Easy 1-page checkout without forced registration (Guest Checkout enabled).

     - Customer shipping address form with phone number verification/input.

     - Cash on Delivery (COD) & Online Payment integration options.

     - WhatsApp Order Option: A button that allows users to place/confirm their order directly via WhatsApp chat.

   - About Us / Hakeem Profile Section: Brief intro about Anmol Dawakhana’s heritage, authenticity, and commitment to pure ingredients.

   - Contact & Consultation Section: Address, phone number, Google Maps location placeholder, and an "Online Consultation / Hakeem se Rabta" form.

5. User Experience (UX):

   - Instant visual feedback on adding items to cart.

   - Extremely clear and simple language, avoiding overly complex medical terms.

   - Sticky Bottom Navigation Bar for mobile users (Home, Categories, Cart, Contact).
